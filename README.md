Official code and dataset for the paper:

> **Explainable hybrid stacking ensemble for robust smart grid stability assessment under cyber–physical disturbances**
> Abu Shufian, Md. Asif Khan, Rajin Al Fatemi, F. M. Mahir Daiyan, Md. Ashiquzzaman & Shaikh Anowarul Fattah
> *Scientific Reports* **16**, 32080 (2026). https://doi.org/10.1038/s41598-026-75252-2

Explainable Hybrid Adversarially Robust Stacking Ensemble (HARSE-SG) for smart grid stability assessment under cyber–physical disturbances.

## Repository contents
- `Cyber_Physical_Smart_Grid_Stability_Code.ipynb` — full experimental pipeline
- `smart_grid_stability_augmented.csv` — augmented dataset used in the study
